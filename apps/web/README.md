# OrgMind Web

Next.js App Router interface for the internal knowledge workspace. Login and registration use the API's Better Auth-backed endpoints, and server-rendered workspace and Members pages check the session before returning protected content.

## Local commands

From the repository root, run `pnpm dev` after MongoDB and Redis are available and the seed administrator has been created with `pnpm db:seed`.
